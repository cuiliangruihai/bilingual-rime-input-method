# 每日中文学习记录

输入法的职责是记录最终提交的中文，不参与句子判断和学习内容分析。这样输入法可以保持轻量，后续 Web 项目也可以独立迭代大模型方案。

## 文件位置

```text
<Fcitx5 用户数据目录>/rime/learning/YYYY-MM-DD.json
```

日期使用系统本地时区。每天只创建一个 JSON 文件。

## 文件格式

```json
{
  "date": "2026-09-07",
  "text": "你好\n我今天想吃苹果\n这个方案还需要继续优化"
}
```

- `date`：文件对应的本地日期。
- `text`：当天所有最终提交的中文文本。
- 每个提交块之间追加一个换行；换行仅用于保留输入块顺序，不代表句子边界。
- 英文输出时仍然记录原始中文，便于后续分析中文表达。
- 未确认的拼音、取消的组合、纯英文和纯数字不会写入。

## 写入特性

- 输入线程只将文本放入内存队列，文件读写由后台线程完成。
- 进程重启后会继续读取当天文件并追加，不会覆盖已有内容。
- 文件先写入 `.json.tmp`，成功后原子替换正式 JSON。
- 文件权限设置为当前用户可读写。
- `LearningLogEnabled=False` 可以关闭记录。

## 后续 Web 处理建议

Web 项目读取 JSON 后，可以自行完成：

1. 根据标点、换行、时间信息或语义重新组合句子。
2. 翻译完整句子，保留自然英文作为例句。
3. 抽取单词、固定搭配和短语。
4. 根据用户学习进度生成复习内容。
